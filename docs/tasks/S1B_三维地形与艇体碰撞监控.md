## 4. 坐标系、区域与场景真值

统一NED：x为北、y为东、z为向下深度，位置米、姿态弧度；体坐标到NED使用现有ZYX旋转约定。绘图可用东/北作为横纵坐标，但必须标明且不改变计算数据。正俯仰的朝向应用旋转矩阵验证，不能凭“深度正向下”推断俯仰符号。

起始开发场景：x、y各在[0,300]米，允许任务深度[5,85]米。任务深度上限不是海底；海底由h(x,y)决定。真正水面在z=0，本卡的5米是操作边界。所有边界都检查整个艇体，不只检查中心。特别注明：原S0默认初态全零，不应被新监控层擅自改写成水下初态。

新监控示例显式设置合法水下初态，原S0/S1-A回归依然用原初态与原入口。为检查“监控不改变轨迹”可使用足够大的深水诊断区域，它只是单元/集成夹具，不伪装成300米正式场景。

场景至少包含：schema_version、scene_id、mother_terrain_id、generator_version、用途development、地形参数、边界、障碍ID与参数、艇体参数、几何判定参数、解析后的随机种子。规范化JSON与确定几何内容共同计算scene_hash；时间戳不得改变同一场景的内容哈希。

生成时使用独立显式RNG，不消费RemusAdapter的RNG。生成一次后持久化实际参数，运行中不重新生成地形。相同参数和种子生成相同内容；绘图、查询、复制不消费RNG。不同种子是否得到不同场景需测试，不只看文件名。旋转、裁剪或微扰保留同一母地形ID。本轮只造少量开发场景，不生成正式440场景测试集。

## 5. 地形定义与地形净空

### 5.1 唯一地形函数

海底是图面z=h(x,y)，其下方实体为z>=h(x,y)。山峰更浅，因此高斯隆起用减号：

```math
h(x,y) = h0 - Σ A_i exp[-0.5 ((x-x_i)^2/σ_xi^2 + (y-y_i)^2/σ_yi^2)]
```

第一版要求A_i>=0、σ_xi>0、σ_yi>0。平底和斜平面用于解析验收，丘陵用若干高斯、山脊用拉长或串联高斯、弯曲通道由左右两侧连续山脊构成。

地形、梯度、净空与绘图都使用同一函数。网格仅用于绘图/加速，不把最近网格点深度当作真实h。若未来采用插值网格，应单独定义插值法、边界与误差，不能在本轮暗中切换真值。

起始生成范围：背景深度80米，3—6个起伏单元，宽度约15—50米，幅值以总幅值不超过55米为约束。可调整各项幅值以满足显式生成约束，但不得事后逐点clip地形掩盖不合法参数。上述约束使本版地形不浅于25米且不深于80米；不要求覆盖完整25—95米范围。

### 5.2 梯度上界与坡面净空

提供`depth_at()`、`gradient_at()`及经过推导的`gradient_bound()`。不能把稀疏网格上测到的最大梯度当作全域严格上界。

对本卡的高斯和，一个可用的全域保守界为：

```math
G := Σ A_i /(sqrt(e) min(σ_xi,σ_yi)),    ||∇h(x,y)|| <= G
```

这里定义G为可计算的保守上界，不声称它等于梯度范数的实际最大值。对斜平面h=h0+a*x+b*y，G=sqrt(a*a+b*b)。实现注释写出归一化半径乘高斯在半径1取得最大值这一依据。

对确定在水中的点q=(x,y,z)，到海底实体的距离下界为：

```math
b(q) = (h(x,y)-z)/sqrt(1+G^2)
```

推导：F(q)=h(x,y)-z的梯度范数不超过sqrt(1+G²)，而海底表面F=0；由Lipschitz不等式得到距离下界。只在F>0时用其认证外部净空。F<=0意味着该点已在实体内或接触边界，不能用“到表面的非负距离”将其判为安全。

这不是一般地形的精确欧氏距离。尤其`h(center_x,center_y)-center_z`只是竖向间距，不是斜坡上艇体的最小净空。

### 5.3 静态地形碰撞不能只凭负下界

一般地形采用：认证下界快速放行；下界不足时细分、局部合法界或高精度几何复核。可以用艇体内/表面的实际见证点落入实体证明相交，必须记录见证点并验证它确属艇体。

当没有证据证明相交、也没有证据认证分离时，返回UNCERTAIN。不能把“下界<=0”直接写为COLLISION，更不能写为CLEAR。解析平面用精确公式，避免简单接触用例也全返回不确定。

## 6. 胶囊艇体与静态障碍

### 6.1 明确胶囊长度含义

本轮实施约定：`total_length_m=1.6`表示包含两个端帽的胶囊总长，`radius_m=0.095`。中心线半长为：

```math
ell = total_length_m/2 - radius_m = 0.705 m
q_minus = position_ned - ell * R_body_to_ned[:,0]
q_plus  = position_ned + ell * R_body_to_ned[:,0]
body = segment(q_minus,q_plus) ⊕ ball(radius_m)
```

所以中心线长1.41米，而不是1.6米；不得无记录地做成总长1.79米。将该解释写入方法映射；如已读取的正式公式明确采用另一种长度定义，列出差异并请求确认，不能静默混用。

这是协议选择的几何近似，不保证包含所有舵面、天线和附件。未有CAD或测量依据，不声称是真实艇外形的严格包络。新增安全裕度与艇体半径分开记录，不通过悄悄放大半径替代风险判据。

### 6.2 对照用的解析距离

- 球体障碍：中心c、半径R。令d=q_plus-q_minus，t=clip(((c-q_minus)·d)/(d·d),0,1)，间隙为||q_minus+t*d-c||-radius_m-R；退化线段单独处理。
- 轴对齐实体长方体：用线段到闭实体盒的最小距离减去艇体半径判断分离或相交。需要处理线段中部穿盒、平行、端点、面/棱/角；不能只测试两个端点，也不能把球体膨胀后的圆角盒误当作无限角点的简单扩张盒来声称精确距离。
- 斜平面h=h0+a*x+b*y：单位化自由侧函数f(q)=(h0+a*q_x+b*q_y-q_z)/sqrt(1+a²+b²)。胶囊间隙为min(f(q_minus),f(q_plus))-radius_m，可用作独立解析真值。
- 任务边界：每个自由侧半空间采用相同端点最小值减半径规则。中心在区域内、头尾越界必须检出。

上述“间隙”在相交时的负值不统一宣称是精确穿透深度。障碍ID、碰撞类型和见证信息应保留。

### 6.3 中心线采样的保守界

若沿中心线含端点采样，最大间隔为Δs，每个点到实体具有有效距离下界b_i，则：

```math
c_lb := min_i(b_i) - Δs/2 - radius_m,    c_true >= c_lb
```

这里令c_true=dist(中心线线段,闭实体)-radius_m，c_lb是它的有效下界；c_true为正时就是胶囊到实体的分离间距，为负时也不等于一般穿透深度。仅在中心线采样点均已确认在实体外时使用上述样本认证。若c_lb为负，它仍只是未能认证分离，不证明发生碰撞。依据为任意中心线点距离最近采样点不超过Δs/2，距离函数满足1-Lipschitz性。

先处理样本已在实体内的情况。减去Δs/2后仍为正可认证；不足时进一步细分或返回UNCERTAIN。细分中心线不会自动把过松的全域地形梯度界变成精确距离，不能因此承诺必定收敛成CLEAR。

## 7. 分开记录碰撞、风险和无法认证

几何查询结构至少包含：

```text
status: CLEAR | COLLISION | UNCERTAIN
reason: terrain | sphere | box | domain_boundary | budget_exhausted | ...
clearance_lower_bound_m
clearance_value_m           # 仅确实得到解析/数值距离时填写，否则null
clearance_kind             # exact_gap / lower_bound / bracket
contact_witness            # 可选见证点/物体ID/接触区间
near_obstacle_status       # SAFE_MARGIN | VIOLATION | UNKNOWN
certified
query_count
```

非法输入抛出明确异常，不返回CLEAR。

数值接触容差建议1e-6米；解析测试误差绝对值不超过1e-6米，并说明浮点边界带。约1米净空是软风险阈值，不是硬碰撞半径。下界小于1米只能说明尚未认证满足安全裕度，不能直接宣称真实间距小于1米；需要真实值/上界才确认风险违反。

只有有效相交证据/解析间隙判定才记已证实碰撞。保守处理可以在UNCERTAIN时停止监控轨迹，但结果计为`uncertified_clearance`，不当作真实碰撞。不得把不确定样本删除、标成功或藏到碰撞总数里。

## 8. 两个物理步之间的扫掠检查

### 8.1 明确定义本轮检查的运动

不能只检查步前和步后。对于相邻0.02秒状态，S1-B显式采用“中心位置线性插值＋姿态最短SO(3)旋转插值”的几何扫掠表示。它不改变积分器，也不是精确连续动力学解。认证结论只对该表示和所选几何模型有效。

使用单位四元数或等价稳定旋转表示，处理q与-q及±180度边界；不得逐项对包裹后的欧拉角直接平均。旋转角π的并列选择需固定规则。记录插值版本。仅凭两个端态不能证明任意未知真实中间轨迹无碰撞。

### 8.2 可用的递归区间证书

对一个插值子区间，令端点中心位移长度为D，姿态相对最短转角为θ∈[0,π]，艇体相对中心最大半径ρ=ell+radius_m。以区间中点为锚点，任意艇体点到对应中点位置的位移不超过：

```math
B = D/2 + 2*ρ*sin(θ/4)
```

这个界来自线性平移与刚体旋转弦长。用区间中点的有效艇体净空下界减去B，若仍大于数值容差，可认证整个子区间无碰撞。

算法先查端点及必要中点。无法放行时递归细分；发现实际接触见证返回COLLISION；达到最大深度/最小时间间隔仍不确定，返回UNCERTAIN。各子区间都被认证才能整段CLEAR。不得仅因起终点安全就提前返回。

建议起始预算：最大递归深度12；中心线初始间隔0.05米，最小间隔0.002米；参数在运行前登记。遇复杂地形时允许不确定，报告比例与成本，不无限递归。实现可更紧，但必须写出正确性依据并有反例测试。

### 8.3 首接触时间

只有算法确实定位首个接触区间，才返回`first_contact_time_interval_s`；否则记“发现接触的证据时刻/区间”和整个步区间，不冒称精确首次接触时刻。

按时间顺序搜索；未认证的更早区间不能被忽略后将更晚接触称为第一次。诊断中间位姿不伪装为积分器计算的完整动力学状态。

## 9. 接入已有适配器：组合，不重写

构造`WorldMonitor`或等价对象，组合一个`RemusAdapter`、一个不可变场景和监控状态。原适配器的reset/step/get_state/set_state/clone语义保持不变。

本轮推荐监控语义：

1. 每次显式执行一个0.02秒物理步；保存步前和步后真实快照，调用扫掠检查。
2. 无碰撞时继续；发生实体碰撞、明确越过任务边界或UNCERTAIN时，记录本步完整信息并标为终止，不再允许下一步推进。
3. 不做碰撞响应、不反弹、不把位置夹回边界、不擦除撞击轨迹、不悄悄回滚后继续。
4. 终止状态保留真实积分步末状态及上一个已认证状态。若步内接触后步末已穿到另一侧，步末状态仅作为已终止尝试的诊断，不称为安全可继续状态。事件时间与步末时间分开记录。
5. 已终止对象再次step须抛明确异常且状态不变；必须reset或合法恢复才能继续。
6. 查询、绘图和快照均不得推进物理或消费随机数。新监控快照组合原RemusSnapshot、场景哈希/版本、监控配置及终止信息，不给原快照偷偷加字段或更改版本。
7. 场景几何数据共享只限真正不可变对象；对外返回可修改数组时必须复制。恢复不同场景哈希/不同几何规则快照必须拒绝且原子失败。
8. 非法初态要明确拒绝，不自动移动到安全位置。原动力学回归用原入口，不让新增边界使原S0必然失败。

本轮固定海流与几何场不耦合，明确说明“仅验证几何监控，不验证海底绕流或固壁无穿透海流”。不把这组演示当作完整海洋物理验证。

## 11. 集成诊断与可见产物

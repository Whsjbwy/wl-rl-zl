## 原循环与步边界

冻结 `lib/mainLoop.py::simulate(N,dt,vehicle)` 使用 `range(0,N+1)`。
每轮先调用自动驾驶并更新控制记忆，随后记录 `[eta,nu,u_control,u_actual]`，
再调用 `dynamics` 更新速度/实际执行器，最后 `attitudeEuler` 用更新后的速度推进位置和姿态。
`dynamics` 原地修改传入 nu；`attitudeEuler` 原地修改 eta。
这保留原有欧拉更新顺序，不重新声称为更高阶积分器。

`RemusAdapter.get_state()` 表示完成 k 次物理更新、尚未计算第 k 次控制指令的边界。
`step(reference)` 返回边界 k+1 及区间 [k*dt,(k+1)*dt) 所用的控制指令，
该快照的七项控制记忆已经由本轮自动驾驶更新。
当前参考表示上一次已执行的参考，下一次参考由调用方显式传入。

原第 k 行物理量等于新接口边界 k；原第 k 行指令等于新接口第 k 次 step 返回的 command。
原循环最后在 200 秒记录一行，然后内部继续到 200.02 秒。
新真实实例只调用10000次 step，停在200秒；末行指令通过独立 clone 的一步预览取得，
该临时分支随即丢弃，主实例与其随机状态保持不变。
日志、JSON序列化、绘图只读取状态或文件，不执行控制器。

## 状态与单位审计

| 字段 | 单位/形状 | 影响与保存方法 |
|---|---|---|
| eta | (6,) float64；北/东/深度 m，roll/pitch/yaw rad | 深度正向下；ZYX姿态；复制数组 |
| nu | (6,) float64；u/v/w m/s，p/q/r rad/s | 艇体坐标速度；原地更新只作用于候选副本 |
| actuator | (3,) float64；rudder/plane rad、rpm | 真正执行器状态，不用指令替代 |
| psi_d/r_d/a_d | rad、rad/s、rad/s² | 航向参考模型的完整三级记忆 |
| e_psi_int | rad·s | 最小角航向误差积分 |
| z_int/z_d | m·s、m | 深度积分和低通参考状态 |
| theta_int | rad·s | 俯仰误差积分 |
| reference | m、rad、rpm | 对应 ref_z/ref_psi/ref_n；公共 rad 在调用上游时转 deg |
| last_command | (3,) rad/rad/rpm | 上一物理步诊断缓存，初态为零；虽然不参与下一次计算也保存 |
| step_count | 非负整数 | time_s=step_count*dt_s，不累计浮点时间 |
| config/config_hash | 不可变 dataclass/SHA-256 | dt、固定海流、初始参考和seed全部进入哈希 |
| rng_state | PCG64 完整字典 | 包含128位状态、增量及缓存；不是仅保存seed |
| version/model_id | 1/固定来源SHA+边界语义版本 | 恢复时严格匹配 |

对冻结 remus100 非构造方法执行 AST 写入审计，全部 self 状态写入恰为上述七项控制记忆。
`self.nu/self.u_actual` 在冻结构造中提供初值；动力学和控制器后续使用显式传参，
适配器的 `_nu/_actuator` 是权威状态，没有额外隐藏的规划/观测缓冲。
质量、阻尼、增益、时间常数与派生矩阵只由同一冻结类构造，保持私有且不提供修改接口。
没有把它们改成新物理参数，也未新增训练或地形占位字段。

固定海流使用原 `nu_c`、`Dnu_c` 表达，位置积分不再额外叠加海流。
上游先限制局部读出的实际舵角/转速，再进行响应更新，因此返回实际舵角可能瞬时越过限幅。
本轮快照只要求这些实际状态有限，不偷偷再限幅；这项已知行为留待后续模型任务。
参考深度合法区间 [0,100] m、参考转速 [0,1525] rpm 与原构造一致。

# S1-B 几何与监控映射

## 协议核对与几何语义

已读取正式方案6.1—6.2正文以及公式（20）对象的原文alt定义：
`r_b=0.095, l_b=(1.6-2r_b)/2=0.705`，与任务卡一致。
这里核对的是文档内的公式文本定义，不声称操作了MathType桌面程序。
胶囊总长包含端帽，不是中心线1.6m再加球；没有CAD或实测依据证明其包络全部附件。
NED以x北/y东/z向下；ZYX正俯仰使艇首向较浅深度转动，与原Rzyx逐元素核对。
开发区300×300m，操作深度5—85m；海底实体为z>=h，操作边界不是海底或真实水面。

地形使用唯一解析函数h=h0+a*x+b*y-高斯和，梯度和绘图直接调用同一对象。
全域梯度界为平面梯度范数加ΣA/(sqrt(e)*min(sigma))；归一化半径u乘exp(-u²/2)
在u=1取最大值，故无需把网格采样最大值冒充严格界。场景生成在参数层约束总幅值≤55m，
地形没有全图clip。三类开发图各一个固定种子，未创建正式封存场景。

平面取两中心线端点到自由半空间的最小有符号间隙减半径。
球体取中心到线段距离减两半径；实体盒按线段坐标穿越各面的参数断点，
在每个区间最小化到闭盒的分段二次距离，包含面/棱/角/中部穿盒/退化线段。
这些负间隙不统一声称为精确穿透深度。

一般曲面：水中点的F/sqrt(1+G²)是距离下界；中心线全采样后再减最大间隔的一半及艇体半径。
实际中心线点或中心线点沿内法向移动不超过半径的见证落入实体才证明相交。
负下界不证明碰撞，细分预算耗尽则UNCERTAIN；静止不确定不能靠重复时间细分改善。
软裕度1m只有真实解析间隙/见证能证明违反，下界不足仅记UNKNOWN；接触带独立为1e-6m。

## 扫掠和监控时序

扫掠版本linear-position-shortest-so3-v1：中心位置线性、姿态最短SO(3)插值。
四元数规范化并固定等价符号，负点积选择短弧，pi并列采用规范符号确定路径。
中点锚定的移动界D/2+2*rho*sin(theta/4)，rho=0.8m；下界减此界仍大于接触容差才认证全区间。
所有子区间都认证才能CLEAR；必要时先搜索左子区间，再搜索右子区间，达到预算返回UNCERTAIN。
发现接触时保存证据时刻及其所在区间，不定位精确首次接触；未认证更早区间不会被隐去。
插值中间姿态不是积分器生成的完整动力学快照；该证书不保证未知真实连续运动安全。

WorldMonitor持有适配器独立副本，每次显式执行一个0.02s物理步后记录扫掠。
事件保留真实步前、真实步后、上次认证状态、场景哈希和全部原RemusSnapshot。
碰撞、操作越界、uncertified_clearance分别终止；终止步末可能在实体另一侧，不能继续使用为安全状态。
不回滚、不反弹、不裁剪位置。克隆与恢复包含终止状态，恢复时重新核对事件几何证据。
查询/保存/绘图不消费RNG或推进状态。固定海流未与海底耦合，不验证绕流或完整海洋物理。
